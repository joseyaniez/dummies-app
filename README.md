# Dummies 3D webpage

Website for displaying 3D products, including their prices, photos, and availability. This webpage allows users to view products and contact the seller.

## Features:

- CRUD operations for products: title, description, price, and availability.
- Allow users to upload one or more images through the form.
- Authentication using username and password.
- Session management with cookies stored in the database.
- Database migrations and seeders.
- Store uploaded images on the server.
- Generate HTML templates using Templ.
- Use HTMX for navigation and user interactions.
